# Better Pterodactyl - 翼手龍面板前端優化項目

Better Pterodactyl 是一個專注於 Pterodactyl 面板前端（React）介面優化與本地化的開源項目。旨在不影響後端邏輯的前提下，透過重構組件樣式與優化交互流程，提供使用者與系統管理員更直觀、專業的操作體驗。

---

## 核心優化項目

### 1. 介面設計語言重構
- **現代化組件樣式**: 引入層次化的邊框設計，提升元件質感。
- **排版與視覺間距調整**: 優化導航欄、卡片組件與字體，提升資訊閱讀效率。
- **動態交互細節**: 增加細微的過渡動畫與 Pulse 特效（如頭像與按鈕），強化操作反饋。

### 2. 功能性顯示優化
- **重構視窗**: 將原本分散的分頁內容整合為個人化卡片形式。

### 3. 本地化支持 (Localization)
- **完整的繁體中文修正**: 修正原始翻譯中生硬的語句，採用更符合開發者習慣的專業術語。
- **全局語系一致性**: 確保所有新增組件均支持 i18next 語系架構，提升翻譯語言的易達性。
- **多語系支持**: 目前支援繁體中文 (`zh`)、英文 (`en`) 與日文 (`ja`)。

## 語系設定 (Language Configuration)

本項目支援多國語言，您可以根據需求進行切換：

### 1. 調整登入頁面語言
由於登入前無法讀取使用者設定，我們提供了一個專用的前端設定檔：
- **路徑**: `resources/scripts/config.ts`
- **操作**: 修改 `login_language` 欄位（可選：`zh`, `en`, `ja`）。
```typescript
const config = {
    login_language: 'ja', // 將這裡改為您預設想要的語言
    // ...
};
```

### 2. 調整系統全局語系
您可以透過 Pterodactyl 的管理員面板或 `.env` 進行調整：
- **環境變數**: 修改 `.env` 中的 `APP_LOCALE=zh`。
- **管理員面板**: 於 `Settings` -> `Basic` -> `Default Language` 進行選擇。

### 3. 個人語言偏好
登入後，使用者可在個人的 `Account Settings` 中設定自己偏好使用的介面語言。

## 安裝與部署
> [!IMPORTANT]
> 本項目仍處於開發階段，各版本組件可能存在嚴重差異，請注意風險。

### 安裝前準備
1. 確保您的 Pterodactyl 版本與本專案版本號對齊。
2. 務必備份原有的 `resources` 資料夾。

### 安裝流程
目前採手動替換方式：
1. 下載對應版本的原始碼。
2. 替換面板目錄下的 `resources` 資料夾。
3. 於面板目錄重新執行面板的編譯指令`yarn build:production`
